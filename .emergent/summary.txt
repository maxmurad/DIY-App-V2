<original_problem_statement>
The user wants to build a comprehensive DIY home repair mobile app.

**PRODUCT REQUIREMENTS (Phase 1 MVP):**
-   **Core Feature:** An AI-powered visual diagnosis system. Users can upload a photo or a short video to diagnose a home repair issue.
-   **AI Backend:** Use a Large Language Model to analyze the media and text.
-   **Output:** The AI should generate a detailed, step-by-step repair project.
-   **Frontend:** A multi-screen mobile app for iOS.
-   **Database:** Use MongoDB to store projects.

**New Features Implemented in this Session:**
-   **Conversational AI (Handy Hank):** Instead of an instant diagnosis, the app now initiates a chat with an AI personality named Handy Hank. Hank asks clarifying questions (limited to 3-4) before generating a tailored project plan. The chat starts immediately after a user uploads a photo/video.
-   **AI Image Slideshows:** For each step in the generated project, the user can tap a button to generate on-demand AI illustrations using Google's Imagen 4.0. The generation process is context-aware, using Gemini to first analyze the user's original diagnostic photo to create more relevant images.
-   **Basic AR Guide:** A new AR Guide feature provides a simple camera overlay with repair instructions. This is marked as an Experimental feature.
